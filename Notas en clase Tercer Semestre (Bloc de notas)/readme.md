# PresuFácil — Presupuesto Maestro para Dulces del Norte

Proyecto Integrador de Aprendizaje de **Contabilidad Administrativa**, Licenciatura en Tecnología de Información, FACPYA-UANL, Ago-Dic 2026.

## Qué es

Una página web que arma el Presupuesto Maestro completo de una empresa a partir de un formulario de supuestos. Con los datos que trae por defecto, calcula todo el presupuesto del caso **Dulces del Norte, S.A. de C.V.** (una empresa ficticia de galletas artesanales en Monterrey).

## Cómo abrirla

1. Descarga la carpeta completa.
2. Ábrela con **Visual Studio Code**.
3. Si tienes Live Server instalado, clic derecho en `index.html` → *Open with Live Server*.
4. Si no, basta con abrir `index.html` con doble clic en cualquier navegador.

> Necesitas conexión a internet la primera vez, solo para cargar Chart.js y las tipografías de Google.

## Qué incluye

- Formulario de supuestos editable con recálculo automático.
- Ocho presupuestos y estados financieros (ventas, producción, compras de MP, MOD, GIF, gastos de operación, estado de resultados y flujo de efectivo).
- Cuatro gráficas en el dashboard.
- Exportación del resumen a CSV.
- Guardado automático en el navegador (localStorage).
